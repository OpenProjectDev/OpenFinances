# Icons

The source repository doesn't include these icon files: their license doesn't allow offering them for download. Get each one from [Flaticon](https://www.flaticon.com) under its own license, and credit its artist. The app credits them all in Settings > About.

Flaticon's address for an icon ends in its ID: `flaticon.com/free-icon/<name>_<id>`.
